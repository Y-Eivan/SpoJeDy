Soal
Case
SpoJeDy
In this project, you are a programmer working at a company called 
Jedy
, where you and your team are trusted to build a music streaming website named 
SpoJeDy
. Through this platform, users can explore and search for songs, listen to music anytime, and watch music videos from various artists. The story of 
SpoJeDy
 reflects how the 
Jedy
 development team transforms ideas into a complete web application, focusing on delivering an enjoyable and seamless entertainment experience while showcasing the students’ skills in designing, developing, and integrating multimedia features into a modern web platform. Your task is to develop the front-end using 
VueJS
 with criteria as follows:
You will need to provide Navigation Bar to Navigate into Home Page, Music Video Page, and Profile Page. In this Navigation Bar, it also shows information about the Username and Profile Image.
The web consists of a total of 5 Pages that are:
Home Page
Home Page will show the list of songs that 
SpoJeDy
 provided. 
It will show information about:
Song Title
Song Artist
Song Cover Image
Notes: You only need to provide dummy data for this list of songs (minimum 2 songs
)
 and you must make sure that the Song Cover Image are fetched from CDN. (recommend using 
imageKit
 CDN)
When user clicks on the song in this list, it will redirect to the clicked Song Detail Page.
Song Detail Page
Song Detail Page will show user’s clicked Song Detail. 
In this page user can: 
play the song
pause the song
change the volume
go to the next song
go to previous song. 
In this page it will also show the Song Cover Image, and when the user clicks it, it will view the image as Full Screen. 
When the Song Cover Image is 
FullScreen
, 
user
 can zoom in or zoom out the Image. Make sure user can exit 
fullscreen
.
It is preferred to use CDN to store Song Audio File.
In this page, user can also click a button to redirect to the Song’s Music Video Detail Page.
Music Video Page
Music Video Page will show the list of Music Video that 
SpoJeDy
 provided. It is the same as Song Data in Home Page, but users can watch Music Video instead of only listening to Song audio. 
It will show information about:
Music Video Title
Music Video Artist
Music Video Cover Image
Notes: You only need to provide dummy data for this list of music videos (the same length as the songs), and you must make sure that the Music Video Cover Image are fetched from CDN. (recommend using 
imageKit
 CDN)
When users click on the music video in this list, it will redirect to the clicked Music Video Detail page.
Music Video Detail Page
Music Video Detail Page will show user’s clicked Music Video Detail. 
In this page user can: 
play the music video
pause the music video
change the volume
go to the next music video
go to previous song
fullscreen
 the music video. 
You must use CDN to store Music Video File.
In this page, user can also click a button to redirect to the current Song Detail Page.
Profile Page
Profile Page will show the user’s information such as username, profile image, and theme preferences (Dark Mode or Light Mode). User can:
Change username
Upload profile image. The profile image must be compressed with maximum size of 1 MB and stored as blob. You must also include a progressive loading animation.
Change theme preferences. When user changes the preferences, it will also change all other page’s UI according to the current theme preferences.
You must store every profile data into local storage.
Notes:
Before uploading your answer, make sure you have deleted the node modules.
You must create internal documentation (it is inline comment in your project that explains your code) and external documentation (using docs that explain what features you have made in each page, preferably using screenshots).
Zip everything in your 
vue
 project excludes node modules and the external documentation.
